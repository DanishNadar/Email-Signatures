      Installing your signature

      Every variant is table-based HTML with inline styles and hosted images, the format mail clients handle most consistently. Rendering will still differ slightly between clients: fonts fall back to Arial, Outlook for Windows ignores rounded corners, and dark mode recolors text in some apps. Treat the Studio preview as a close approximation, not a pixel-perfect guarantee.

      Before installing: exported HTML loads images from . Push the assets/ folder to GitHub Pages first and check that the export bar shows every hosted image as reachable. Otherwise recipients will see alt text instead of images.

      Gmail (web)

      1. Select a variant in the Studio and click Copy signature for Gmail.
      2. In Gmail, open Settings (gear) → See all settings → General → Signature → Create new.
      3. Click inside the signature box and paste (Ctrl/⌘+V). Do not use “Paste as plain text”.
      4. Under Signature defaults, choose it for new emails and replies.
      5. Optionally tick “Insert signature before quoted text in replies”, then click Save Changes at the bottom of the page.

      Gmail allows signatures up to 10,000 characters, and the export bar shows the current count. Gmail strips embedded (data:) images, which is why the variants use hosted URLs. The Gmail mobile apps use the web signature unless a separate “Mobile signature” is set in the app. That setting is plain text and replaces the rich signature, so leave it empty.

      Outlook on the web / new Outlook for Windows

      1. Click Copy signature for Gmail. The copied rich HTML works in Outlook too.
      2. Go to Settings → Account → Signatures → + New signature, name it, and paste into the editor.
      3. Set it as the default for new messages and replies/forwards, then Save.

      Classic Outlook for Windows

      1. Click Download .html and open the file in Edge or Chrome.
      2. Select everything on the page (Ctrl+A) and copy it.
      3. In Outlook, open File → Options → Mail → Signatures… → New, then paste into the editor and save.

      Classic Outlook renders email with Microsoft Word, so the circular headshot is a transparent PNG rather than a CSS-rounded image. Expect small spacing differences. To install from the file directly, copy the .html into %APPDATA%\Microsoft\Signatures\.

      Outlook for Mac

      1. Copy with Copy signature for Gmail.
      2. Outlook → Settings → Signatures → +, paste into the editor, and save.

      Apple Mail (macOS)

      1. Open the downloaded .html in Safari, press ⌘+A, and copy.
      2. Mail → Settings → Signatures. Select the account and click +.
      3. Uncheck “Always match my default message font”, then paste into the right-hand pane.

      Apple Mail may show remote images as blank in the settings pane until they load. That is normal. iOS Mail has no rich-signature editor. Pasting there usually keeps the formatting, but you may need to shake the device to undo its automatic restyling.

      Known limitations

      • Dark mode: Gmail and Outlook apps invert or lighten text automatically. Images are not inverted, so the headshot and monogram use transparent corners and work on both backgrounds.
      • Blocked images: every essential detail (name, role, school, email, links) is real text. Images fall back to short alt text.
      • Mobile: the layout stays around 400px wide and lines break between items, not mid-phrase. Some apps scale wide signatures down instead of wrapping them.
      • Live testing: the Studio and npm run screenshots simulate rendering in Chromium. Send a test email to yourself in each client you rely on before relying on it for important outreach.
